# Gridiron Guessers

Weekly challenge results, playoff bracket and running winnings for the Gridiron
Guessers fantasy league.

**https://monki5922.github.io/gridiron-guessers/**

Everything on the page is computed in the browser from Sleeper's public API each
time it loads — there is no build step and nothing is stored. A week settles once
its Tuesday 6am PT lock has passed and scores exist, and past weeks are
recalculated from Sleeper's frozen per-week rosters, so results never drift.

## The money

| | |
| --- | --- |
| Buy-in | $30 × 12 = $360 |
| 1st / 2nd / 3rd | $100 / $60 / $30 |
| Weekly challenge | $10 × 17 weeks = $170 |

No weekly high-score prize — the side challenge is the only weekly money.
`100 + 60 + 30 + 170 = 360`, exactly the pot.

Ties split the prize. Season prizes are settled by hand after the playoffs.
